# Baseball Game

카이로소프트 감성의 픽셀 아트와 야구 구단 경영의 재미를 결합한 타이쿤 시뮬레이션 프로젝트입니다.

신생 야구 구단의 구단주가 되어 선수를 발굴하고, 구장을 성장시키고, 시즌을 운영하며 제한된 시간 안에 명문 구단을 만드는 경험을 목표로 합니다.

## One-Liner

> 신생 야구 구단의 구단주가 되어, 선수를 발굴하고 구장을 키우며 N년 안에 최고의 명문 구단을 만드는 픽셀 경영 시뮬레이션

## Project Direction

- 장르는 `픽셀 야구 타이쿤`입니다.
- 플레이어의 역할은 `감독`이 아니라 `구단주`입니다.
- 핵심 재미는 `선수 수집`, `육성`, `시즌 운영`, `구단 확장`, `장기적인 왕조 구축`에 있습니다.
- 경기 개입보다는 `관전과 의사결정`, `경영 판단`, `로스터 구성`에 초점을 둡니다.

## Core Loop

1. 드래프트와 스카우팅으로 선수를 확보합니다.
2. 스프링캠프와 운영 방침으로 팀 전력을 성장시킵니다.
3. 시즌을 진행하며 경기 결과, 재정, 팬 반응을 관리합니다.
4. 수익과 성과를 바탕으로 구장과 구단 인프라를 확장합니다.
5. 다음 시즌에 더 강한 팀과 더 큰 목표로 도전합니다.

## What Makes It Different

- `구단주 시점`: 직접 플레이보다 위에서 팀을 설계하고 운영하는 감각을 강조합니다.
- `관전 중심 경기 경험`: 하단 티커, 빅매치 관전, 위기 상황 의사결정으로 몰입을 만듭니다.
- `성장하는 구단`: 선수만이 아니라 구장, 스태프, 팬 기반, 지역 선택까지 함께 성장합니다.
- `리플레이 가치`: 지역 기반 가상 구단, 동기 라이벌, 시즌 목표, 장기 레거시 평가를 통해 반복 플레이 재미를 노립니다.
