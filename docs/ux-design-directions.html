디자인 방향 요약: "미니 월드" + 사이드 메뉴

핵심 컨셉: 아이소메트릭 구장을 중심으로 한 미니어처 세계. 메뉴 버튼(☰)을 누르면 왼쪽에서 사이드 메뉴가 슬라이드 인되며, 구장 배경은 항상 메인 화면에 유지된다. 탭 바를 제거하여 메인 영역을 최대한 넓게 확보하고, 구장 성장의 시각적 보상을 극대화한다.
요소 설계 방향
네비게이션 좌측 사이드 메뉴 (☰ 버튼 토글). 메뉴 밖 영역 터치로 닫기. 자주 쓰는 기능에 뱃지 표시
메인 화면 아이소메트릭 구장 뷰 — 캐릭터가 돌아다니고, 시설이 해금되면 새 건물과 활동 등장
경영 UI 사이드 메뉴에서 기능 선택 → 구장 위 반투명 오버레이 패널로 표시
티커 하단 고정. 스코어보드 스타일. 경기 진행 중 항상 표시
긴급 팝업 전체 화면 어둡게 + 중앙 팝업. 2~3개 선택지
컬렉션 사이드 메뉴에서 진입. 전체 화면 전환. 선수 도감/업적 하위 탭
낮/밤 경기 시간대에 따라 팔레트 시프트 (하늘색 변화, 조명 효과)
사이드 메뉴의 장점:
• 메인 영역을 최대로 활용 — 구장 성장이 한눈에 보임
• 메뉴 항목을 자유롭게 확장 가능 (아이콘+텍스트 라벨)
• 새 알림이 있는 메뉴에 뱃지 표시
• 왼손/오른손 모두 ☰ 버튼 접근 가능 (상단 좌측 배치)

주의사항:
• 사이드 메뉴 오픈은 반드시 ☰ 버튼 또는 좌측 스와이프로 제한
• 경기 중 핵심 인터랙션(긴급 팝업 응답)은 메뉴 없이 바로 접근
• 메뉴 오픈 시 티커는 계속 표시 (경기 놓치지 않도록)
