## Technique Execution Results

### Phase 1: Inner Child Conference

**탐색 방향:** 7살 어린이의 순수한 시각에서 "야구 게임에서 진짜 재미있는 것"을 찾기

**핵심 발견:**
- "좋은 선수들로 팀을 꾸려서 엄청 강한 팀을 만들고 싶다" → 수집의 쾌감이 핵심 욕구
- 강한 팀은 홍보 효과를 가져오고 이는 다음 시즌의 자금력으로 이어짐 → 선순환 경영 사이클 발견
- 구단주 vs 감독 역할의 상충 문제 → 위임 시스템의 필요성 도출
- 경기 하나하나를 직접 컨트롤하면 피로해짐 → 하단 티커 실황 + 경영 멀티태스킹 구조 착안

**생성된 아이디어:** #1~#23

### Phase 2: Chaos Engineering

**파괴 시나리오 4가지 스트레스 테스트:**

1. **"3시즌 연속 꼴찌"** → 역드래프트 보상, 언더독 이벤트, 리빌딩 전략으로 해결
2. **"너무 쉬워서 지루함"** → 왕조 시스템, 시즌 등급 리포트, 도전 과제로 해결
3. **"경기를 안 보는데 야구 게임 맞아?"** → 빅매치 풀 관전 + 구단주 결단으로 해결
4. **"수익 모델"** → 보상형 광고 + 프리미엄 모델 + 게임 내 가상 스폰서로 해결

**생성된 아이디어:** #24~#46

### Phase 3: Analogical Thinking

**참조 도메인과 이식된 패턴:**

- **서바이벌 예능** → 스프링캠프 서바이벌 경쟁, 로스터 컷 드라마, 반전 각성 캐릭터
- **프린세스 메이커** → 선수 성격 시스템, 구단주-선수 신뢰도
- **카이로소프트 섬/도시 키우기** → 구장 주변 도시형 개발 (→ 해금 방식으로 발전)
- **아이돌 프로듀싱** → 선수 성장 서사, 케미/궁합 시스템

**생성된 아이디어:** #47~#81

## Session Summary and Insights

### 핵심 성과

1. **게임 정체성 확립:** "선수를 모으고, 구장을 키우는" 구단주 경영 시뮬레이션
2. **카이로소프트와의 차별점 발견:** 하단 티커 경기 시스템, 해금식 구장, 뉴스 기반 세계관, 서바이벌 스프링캠프
3. **4가지 극한 시나리오 검증 완료:** 꼴찌/지루함/야구감 부족/수익 모델 모두 해결책 도출
4. **수익 모델 방향 확정:** 무료+보상형 광고+유료 광고 제거. 초기 손실 감수하고 유저 확보 우선

### 브레이크스루 순간들

- **"경기를 하단에 깔고 위에서 경영한다"** — 기존 야구 게임과 완전히 다른 시점 발견
- **"시스템이 라이벌을 정하지 않고, 경험이 라이벌을 만든다"** — 제로 코드로 강력한 감정 유발
- **"해금이 직접 배치보다 낫다"** — 게임 정체성을 지키면서 성장감 확보
- **"12팀 + 동기 구단"** — 홀짝수 문제 해결 + 자연 라이벌 확보를 동시에

### Creative Facilitation Narrative

youme님은 "강한 팀을 만들고 싶다"는 순수한 욕구에서 출발해, 구단주의 역할 정의, 경기 관전 방식, 수익 모델까지 자연스럽게 확장해 나갔다. 특히 아이디어를 받아들일 때보다 **거절하거나 수정할 때** 게임의 정체성이 더 명확해졌다. "선수 스케줄은 과하다", "직접 배치보다 해금이 낫다", "NPC는 피로하다" 같은 판단들이 이 게임을 "이것저것 다 하는 게임"이 아닌 **"구단주의 게임"**으로 깎아냈다.
