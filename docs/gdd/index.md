# Game Design Document - 픽셀 야구 타이쿤

## 문서 목적

이 GDD는 픽셀 야구 타이쿤의 MVP 게임 규칙, 시스템 구조, 플레이 흐름을 정의한다.

PRD가 제품 목표와 요구사항을 다룬다면, GDD는 실제 게임 안에서 각 시스템이 어떻게 작동하고 서로 어떻게 연결되는지를 다룬다.

## 게임 개요

플레이어는 신생 야구 구단의 구단주가 되어 선수를 확보하고, 구장을 성장시키며, 10시즌 안에 명문 구단을 만드는 것을 목표로 한다.

게임은 현실 야구 규정의 정밀한 재현보다 모바일 타이쿤에 맞는 짧은 시즌 템포, 명확한 선택, 구단 성장감을 우선한다.

## 핵심 경험

- 내가 직접 고른 선수가 성장하는 애착
- 시즌이 흐르며 구단이 강해지는 성장감
- 구장 시설이 해금되며 할 수 있는 일이 늘어나는 타이쿤 감각
- 짧은 시즌 단위로 반복되는 경영 판단
- 경기 조작보다 구단주 관점의 선수 확보, 운영, 투자 판단

## MVP 핵심 루프

```text
구단 창단
→ 창단 드래프트
→ 창단 FA
→ 초대 감독 선임
→ 창단 스프링캠프
→ 시즌 1 진행
→ 트레이드 데이
→ 시즌 종료 리포트
→ 정규 드래프트
→ 정규 FA
→ 감독 연임/교체
→ 스프링캠프
→ 다음 시즌 진행
```

스폰서는 매 시즌 반드시 선택하는 핵심 루프가 아니라, 구단 업적과 시설 성장에 따라 해금되는 보너스 시스템으로 분리한다.

## 시즌 구조

- 게임은 최대 10시즌 진행을 기본 목표로 한다.
- 시간은 `시즌 1 / 4월 1주차`처럼 시즌 번호와 월/주차를 함께 표시한다.
- 게임 시간은 기본적으로 자동으로 흐른다.
- 선택이 필요한 오버레이가 열리면 게임 시간은 일시정지된다.
- 오버레이가 닫히면 게임 시간은 자동으로 다시 흐른다.
- 정규 시즌은 주 단위로 진행되며, 각 주차마다 1경기가 자동 진행된다.
- 11팀 리그의 각 구단은 다른 10팀과 홈 1경기, 원정 1경기씩 총 20경기의 정규 시즌을 치른다.
- 정규 시즌 경기 결과는 하단 티커로 표시한다.
- 정규 시즌 중에는 경기 개입 팝업을 제공하지 않는다.
- 포스트시즌은 정규 시즌보다 강조된 하이라이트 티커와 제한적 위기 상황 팝업으로 처리한다.
- MVP에서는 풀 관전 모드를 제공하지 않고, Post-MVP에서 포스트시즌 빅매치 풀 관전 모드를 검토한다.

## 설계 원칙

- MVP는 한 시즌을 20분 전후로 완료할 수 있어야 한다.
- 첫 시즌은 튜토리얼과 창단 과정을 포함하므로 25~30분까지 허용한다.
- 플레이어가 직접 조작하는 횟수는 적게 유지하되, 중요한 선택은 놓치지 않게 한다.
- 시간은 자동으로 흐르되, 오버레이가 열리면 정지한다.
- 시설은 단순 수치 보너스가 아니라 새로운 행위 또는 시스템을 해금해야 한다.
- 선수 정보는 숫자보다 등급과 태그 중심으로 빠르게 이해 가능해야 한다.
- 드래프트, FA, 스카우트, 트레이드는 모두 선수 확보/발굴의 하위 시스템으로 다룬다.
- 현실 야구 규칙보다 모바일 타이쿤의 템포와 명확성을 우선한다.
- MVP에서 복잡한 확률 협상, 선수 성격/케미, 정교한 규정 제한은 제외하거나 Post-MVP로 둔다.

## MVP 범위

- 11팀 리그
- 10시즌 진행
- 시즌당 정규 시즌 20경기
- 주차 단위 자동 시간 진행
- 오버레이 기반 일시정지
- 하단 티커 경기 표시
- 창단 드래프트
- 정규 드래프트
- 창단 FA
- 정규 FA
- 내부 FA 잔류/방출
- 즉시 결과형 스카우트
- 시즌 중반 트레이드 데이
- 감독 선임 및 시즌 종료 후 연임/교체
- 스프링캠프
- 구장 맵과 시설 해금
- 스폰서 해금 보너스
- 포스트시즌 하이라이트 티커
- 시즌 종료 리포트

## Post-MVP 후보

- 포스트시즌 풀 관전 모드
- 정규 시즌 중요 경기 위기 팝업
- 선수 성격 시스템
- 선수 케미/갈등
- 고급 팬 이벤트
- 유소년 아카데미 심화
- 시설 업그레이드 심화
- 메이저 포스팅/복귀 이벤트
- 온라인 랭킹
- 뉴게임+ 보너스 심화
- iOS 출시

## 미결정 사항

- 정규 시즌과 포스트시즌의 정확한 월별 배치
- 포스트시즌 진출 팀 수와 경기 방식
- 선수 등급별 내부 수치 범위
- 시설별 MVP 최종 목록과 해금 조건
- 경제 밸런스의 기준 단위
- 자동 시간 흐름의 실제 속도와 배속 정책
