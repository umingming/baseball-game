# Product Brief: 픽셀 야구 타이쿤

> 신생 야구 구단의 구단주가 되어, 선수를 발굴하고 구장을 키우며 10년 안에 최고의 명문 구단을 만드는 픽셀 경영 시뮬레이션

---

## 제품 개요

**장르**: 픽셀 아트 야구 구단 경영 시뮬레이션 (타이쿤)
**플랫폼**: 모바일 (iOS / Android)
**아트 스타일**: 픽셀 아트 (월간아이돌, 카이로소프트 감성)
**플레이 시간**: 한 판 5~7시간 (10시즌, 시즌당 30~40분) / 2회차부터 배속 가능
**수익 모델**: 무료 + 보상형 광고 + 프리미엄 광고 제거 (5~7천원)

## 왜 이 게임인가

모바일 야구 게임 시장은 카드 수집 액션(컴투스 프로야구)과 하드코어 통계 시뮬(OOTP)로 양분되어 있다. 그 사이에 **"내 손으로 키우는" 육성형 야구 경영 게임은 존재하지 않는다.**

월간아이돌(2인 개발, 100만+ DL)은 아이돌 기획사 경영이라는 구조로 10~30대 유저를 사로잡았다. 연습생 캐스팅 → 육성 → 앨범/콘서트 → 기획사 성장이라는 루프는 야구 구단 경영(드래프트 → 육성 → 시즌 → 구단 성장)과 본질적으로 동일하다. 이 검증된 재미를 야구 팬이라는 명확한 타겟에 결합하면, 아직 아무도 점유하지 않은 시장을 열 수 있다.

## 핵심 컨셉

### 구단주 시점

플레이어는 감독이 아니라 **구단주**다. 경기를 직접 조작하지 않는다. 선수를 뽑고, 감독에게 방침을 내리고, 구장을 확장하고, 스폰서를 유치하고, FA 시장에서 협상한다. 감독 업무는 NPC 감독에게 위임하되, 핵심 순간에만 구단주로서 결단을 내린다.

### 관전 중심 경기 경험

평소 경기는 화면 하단 티커로 결과가 흘러가고, 플레이어는 그 위에서 경영 업무를 처리한다. 포스트시즌 빅매치만 풀 관전 모드로 전환되며, 이때도 조작이 아닌 "지켜보는 재미"에 집중한다. 9회말 동점 같은 위기에는 구단주 결단(선수 교체 승인 등)이 요구된다.

### 성장하는 구단

허름한 구장이 명문 구단의 홈으로 바뀌는 과정이 메인 화면에서 시각적으로 드러난다. 시설은 직접 배치가 아닌 **해금 방식** — 자금과 업적 조건을 달성하면 실루엣이었던 시설이 열린다. 해금 순서가 곧 전략이다(투수 훈련 시설 먼저 vs 팬 편의 시설 먼저).

## 핵심 게임 루프

```
드래프트/스카우트 → 스프링캠프 → 시즌 운영 → 성과 평가 → 구장/구단 확장 → 다음 시즌
```

1. **선수 확보** — 안목의 쾌감
   드래프트 지명, 스카우트 파견, 무명 원석 발굴, FA 영입, 트레이드, 메이저 복귀 선수. 능력치가 ???로 가려진 무명 선수를 안목으로 골라내는 것이 핵심. 가챠가 아닌 "내 눈"으로 찾는 재미.

2. **팀 구성** — 전략적 선택
   감독에게 방침 설정(장타/기동력/투수력), 로스터 편성. 선수 간 케미와 궁합이 조합의 깊이를 만든다. 감독 성향과 방침이 맞아야 팀이 돌아간다.

3. **시즌 진행** — 지켜보는 긴장감
   하단 티커로 경기가 흘러가는 동안 경영 업무를 처리하는 멀티태스킹. 평소엔 구단주답게 일하다가, 9회말 동점 같은 위기에만 "구단주님, 결정이 필요합니다!" 팝업. 포스트시즌 빅매치는 풀 관전 모드로 전환 — 내가 지명한 신인의 끝내기 홈런을 귀빈석에서 지켜보는 순간.

4. **평가와 보상** — 성찰의 시간
   시즌 등급 리포트(D~S). 우승해도 재정이 엉망이면 A가 한계. 경영까지 잘해야 S. 10년 전체를 관통하는 레거시 점수가 누적되며, 초반 꼴찌에서 후반 왕조로 가는 곡선이 가장 높은 점수를 받는다.

5. **구단 확장** — 눈에 보이는 성장
   수익으로 시설 해금, 스폰서 유치, 유소년 아카데미 투자. 실루엣이었던 시설이 하나씩 열리며 허름한 구장이 명문 홈구장으로 바뀌어가는 과정이 메인 화면에서 직접 보인다.

6. **10년 후 선택** — 레거시의 완성
   10년간의 경영을 종합 평가. **계속 경영**(왕조 유지 도전)으로 명문 구단의 역사를 이어가거나, **뉴게임+**로 새 도시에 새 구단을 창단. 이전 회차의 S등급 항목이 다음 회차에 소폭 보너스로 이어진다.

## 차별화 포인트

| 기존 게임 | 이 게임 |
|----------|--------|
| 감독/GM 시점 | **구단주 시점** — 구장, 스폰서, 팬, 인사 |
| 경기 직접 조작 | **하단 티커 관전 + 경영 멀티태스킹** |
| 구장은 배경일 뿐 | **해금식 구장 성장이 핵심 보상** |
| 시스템이 라이벌 지정 | **자연 발생 숙적** (FA 빼간 팀에 대한 감정) |
| 실존 구단 라이선스 | **가상 12팀 리그** + 전국 자유 창단 |

## 세계관과 리그 구조

- 12팀 리그 (기존 10팀 + 신생 2팀). 플레이어는 신생 구단 중 하나의 구단주
- 실제 한국 지역명 + 가상 팀명 (저작권 리스크 없이 현실감 확보)
- 기존 10팀은 매 회차 랜덤 생성 — 리플레이 가치 확보
- 동기 구단이 자연스러운 라이벌. 지역 선택이 곧 난이도 선택
- 세계관은 **스포츠 뉴스/기사 형식**으로 전달. NPC 대화 피로 없음
- 선수의 **메이저 포스팅** 이벤트 — 키운 선수가 해외로 떠나는 아쉬움과 이적료 수익
- 메이저 경험 선수의 **고향팀 복귀** — 낭만과 즉시 전력을 동시에 제공
- 10년 시나리오 종료 후 **계속 경영**(왕조 유지 도전) 또는 **뉴게임+**(새 구단 창단) 선택 가능

## 수익 모델

| 단계   | 모델           | 설명                              |
| ---- | ------------ | ------------------------------- |
| 초기   | 무료 + 보상형 광고  | 스카우트 보고서 추가 열람, 회복 아이템 등 자발적 시청 |
| 전환   | 프리미엄 (5~7천원) | 일시불 광고 제거 + 배속 모드 즉시 해금 + 보너스 스킨 |
| 게임 내 | 가상 스폰서 시스템   | 구장 펜스에 픽셀 로고 — 세계관에 자연스럽게 녹아듦   |

강제 광고 없음. 월간아이돌의 "광고 시청 = 캐스팅 기회"처럼, 광고가 게임 플레이의 자연스러운 선택지로 작동.

## 타겟 유저

**1차 (핵심)**: 월간아이돌 등 육성 시뮬레이션 경험이 있는 10~30대 야구팬
**2차 (확장)**: 카이로소프트 등 경영 시뮬레이션을 즐기는 유저
**3차 (글로벌)**: 일본/북미 야구 문화권의 픽셀 경영 게임 팬

## 시장 기회

- **잠재 타겟**: 한국 내 10~30만 명 (육성 시뮬레이션 팬 ∩ 야구팬)
- **직접 경쟁작**: 없음 (시장 공백)
- **참고 성공 사례**: 월간아이돌 (2인 개발, 100만+ DL), Retro Bowl (픽셀 미식축구, 1000만+ DL)
- **글로벌 확장**: 가상 리그 설정으로 문화권 제약 없음

## 주요 리스크와 대응

| 리스크 | 대응 |
|--------|------|
| 야구 비시즌 이탈 | 시즌 회전이 빠르고(20~30분), 비시즌 경영 콘텐츠(드래프트/트레이드/구장) 풍부 |
| 니치 시장 천장 | 가상 리그로 글로벌 호환, 야구 몰라도 경영으로 즐길 수 있는 설계 |
| 대형 야구 게임과 경쟁 | 완전히 다른 장르 — 보완재 포지셔닝 |

## 출시 전략

**Slim but Complete** — 콘텐츠 볼륨은 줄이되, 핵심 루프(드래프트 → 시즌 → 구장 해금)가 완전히 동작하는 상태로 출시. 브레인스토밍에서 Core/Essential로 분류한 시스템을 1차 출시 범위로, Enrichment/Later는 업데이트로 추가.

- **출시 타이밍**: 2026년 7월 10일 KBO 올스타 브레이크 목표 — 시즌 중반 야구 관심 최고조 시점
- **마케팅**: X(트위터) 등 10~30대 여성 커뮤니티 우선 공략, 야구 커뮤니티 + 육성/경영 게임 커뮤니티 병행
- **업데이트 로드맵**: 출시 후 커뮤니티 피드백 반영 → Enrichment 콘텐츠 순차 추가 → 글로벌 출시

- MAU: 1~3만 명
- 유저 평점: 4.0+ / 5.0
